# 人像評分 4 軸法

<div class="not-prose my-6 bg-red-500/10 border-l-4 border-red-500 rounded-r-lg p-4">
<p class="font-bold text-red-400 mb-2">🔴 一句話定義</p>
<div class="text-sm text-gray-300">

把每張照片先按「畫面主體類型」歸類為 4 種 Label(紅 / 黃 / 綠 / 紫),每個 Label 套用不同的評分主軸與 5 級星等(1-5★)規則,最後依場景代表權決定是否升 Pick(P)。Label 由主體**唯一決定**,評分由主軸決定,Pick 由場景代表權決定 — 三層分離。

</div>
</div>


## 適用情境

- 對自己拍的整批旅行照(人像 + 風光 + 食物混合)做選圖
- 訓練 VLM agent 跑大批量評分 production
- 跟 LR catalog 評等 / 旗標 / 色標(rating / pick / colorLabels)欄位對齊
- 後續送 Evoto AI 人臉精修(Red 軸照片)或 LR 純參數出片(Yellow / Green / Purple)

## 4 軸 Label — 由「畫面主體」唯一決定

<div class="not-prose my-6 bg-yellow-500/10 border-l-4 border-yellow-500 rounded-r-lg p-4">
<p class="font-bold text-yellow-400 mb-2">⚠️ Label 不是視覺分類,是評分軸切換 + 後續工作流分類</p>
<div class="text-sm text-gray-300">

不要用「氛圍好不好」「構圖強不強」來決定 Label。**主體是什麼 = Label 是什麼**,沒有例外。

</div>
</div>


| Label | 主體 | 評分主軸 | 後續工作流 |
|---|---|---|---|
| 🔴 **Red** | 人臉清楚可辨(正面 / 3-4 側 / 部分遮蔽,但能跑 Evoto AI 精修) | 眼神 + 表情 + 笑容 + 頭髮整齊度(四道把關) | 跑 Evoto AI 人臉精修 |
| 🟡 **Yellow** | 人但臉**完全不可辨**(背影 / 剪影 / 太遠 / 動態糊) | 構圖 + 敘事 + 氛圍(三大要素) | 不跑 Evoto,LR 純參數 |
| 🟢 **Green** | 風光 / 室內空間 / 無人(人只是附帶點綴) | 構圖切割 + 場景唯一 + 動態事件 + 技法 | LR 直接出片(無人臉) |
| 🟣 **Purple** | 食物 / 藝術品 / 商品(即使旁邊有杯子餐具陪襯) | 創作物視覺 | LR 直接出片 |

### Label 鐵律(2026-05-10 calibration 後)

- **臉可辨就是 Red** — 即使整組 burst 拍得都不特別好,還是 Red,不能因為「沒特別好看」就降 Purple / Yellow
- **同場景一定同 Label** — 三張酒瓶(一張無杯 + 兩張有杯)都 Purple,不能因為「有杯子」就改 Green;同主角不同 pose 全 Red
- **Yellow 真的看不到臉** — 「人在畫面但被遮 / 剪影 / 主體融入背景」才是 Yellow;臉部任何角度能看清五官 = Red

### Label 命名雙軌(VLM 英文 ↔ LR catalog 繁中)

<div class="not-prose my-6 bg-blue-500/10 border-l-4 border-blue-500 rounded-r-lg p-4">
<p class="font-bold text-blue-400 mb-2">ℹ️ 兩套命名同時存在,不要混用場合</p>
<div class="text-sm text-gray-300">

VLM 輸出與本 skill 內文 → **英文** `Red / Yellow / Green / Purple`
寫入 LR catalog `Adobe_images.colorLabels` → **繁中字串** `紅色 / 黃色 / 綠色 / 紫色`
由 ④ 階段 Catalog SQL 寫入時統一轉換(見 Backlog_5階段SOP §④ + LR_Catalog_SQL寫入安全)。

</div>
</div>

## Rating Scale 1-5★ + 視覺錨點

### ⭐⭐⭐⭐⭐ 5★ — 鐵三角全到位(保守給)

- **Red 5★ 鐵三角**:(a) 看鏡頭 + (b) 燦爛真笑 + (c) 構圖到位 + (d) 氛圍加分 — **缺一即頂多 4★**
- **Yellow 5★**:構圖極強 + 強敘事 + 稀有 mood + 主體與環境完美互動
- **Green 5★**:鐵三角全到位(技法 + 構圖 + 場域感 + 無瑕疵)— 訓練集尚無實證
- 預設 4★ 起跳,5★ 要顯著加分項才升

### ⭐⭐⭐⭐ 4★ — 4 軸有 3 個到位 + 表情不僵(出片級)

**Red 4★ 視覺錨點**:
- 撐傘正面真笑 + 看鏡頭 + 雨景氛圍 → 鐵三角達成
- 柔和微笑 + 構圖好(沒看鏡頭也能 4★)
- 3/4 側角度 + 構圖補回沒燦爛笑
- 稀有 mood(害羞嬌柔 / 整組沒幾張的感覺)即使眼神不在也保留

**Green 4★ 觸發點(達一即可)**:
1. 風光課本式三段式(天-中-地 / 天-建築-水)+ 主體置中 + 左右配重均衡
2. 完美對稱構圖(建築 / 水道 / 橋的左右鏡像)
3. 微裁切後即達標(構圖本體好,邊角小雜訊可後製去除)
4. 慢快門技法成功應用(動靜分離 — 水糊化 + 建築銳利)
5. 同主題多版本擇優(建築 / 風光組裡最乾淨曝光好那張)

### ⭐⭐⭐ 3★ — 沒不可救瑕疵但缺核心元素

- **Red 3★ = 備胎,不入 P** — 「看鏡頭但笑沒起來」 / 「微笑但側臉沒看鏡頭」
- **Green 3★ = 保留層 default,自動升 P** — 場景唯一 + 合焦 + 工整 → 3★+P(比 Red 寬鬆)
- 平光無戲劇 ≠ 1★(最多 3★);構圖鬆 ≠ 1★(最多 2★)

### ⭐⭐ 2★ — 不可救瑕疵 / 與更好版本完全雷同

- 表情僵(嘴角微張但眼神疲憊 + 笑沒「起來」)
- 技術 OK 但與更佳版本完全雷同 → 雷同扣 1★
- 背影但背景路人雜亂 + 構圖普通 + 敘事弱
- 同場景多張中「主體偏離構圖線」(高樓不在三分線 / 中軸)

### ⭐ 1★ — 嚴重不可救(門檻嚴格)

- 失焦(主體不合焦)
- 閉眼 / 半閉眼
- 眼神上吊 / 笑容收攏(笑累了) / 眼神疲憊
- HDR bracket 反曝光變體(Sony auto-bracket 過暗 / 過亮)
- 主體完全消失 / 被遮蔽
- 整體構圖凌亂**無法後製救**(過多競爭元素 + 無清楚主體 + 裁切救不回)

## 軸別評分主軸詳述

### 🔴 Red 軸 — 四道把關(任一掛 → ≤2★)

<div class="not-prose my-6 bg-gray-500/10 border-l-4 border-gray-500 rounded-r-lg p-4">
<p class="font-bold text-gray-400 mb-2">📌 Red 軸鐵律</p>
<div class="text-sm text-gray-300">

任一道失守即降至 2★ 以下,不可救。

</div>
</div>


1. **表情** 自然 vs 僵硬(看肌肉緊繃度)
2. **笑容** 起來 vs 收攏(笑累了) / 太用力 / 假笑
3. **眼神** 有神 vs 疲憊 / 失焦 / 上吊
4. **頭髮整齊度** 順 vs 亂 / 翹起 / 風吹開 ⭐ v2 新增

**v2 慷慨原則**(2026-05-08 校準):
- 「人像不吝嗇保留或給高分」— 表情略有差異 = 感覺就不同 → 多張都可保留高分,不要過度擇優扣分
- 同場景 burst 都笑 + 看鏡頭時可以都 4★,不必強制擇優扣分
- vs v1 過嚴「4 張 burst → 4P + 3 + 2 + 2」 → v2 改「4 張都笑+看鏡頭 = 都 4P」

### 🟡 Yellow 軸 — 三大要素(缺一個降一級)

1. **構圖** leading lines / 三分法 / 對稱
2. **敘事** 主體與環境互動(敲鐘 > 走過 > 純擺拍)
3. **氛圍** 光影 / 天氣 / 場域感

### 🟢 Green 軸 — 構圖切割優先(訓練實證)

<div class="not-prose my-6 bg-blue-500/10 border-l-4 border-blue-500 rounded-r-lg p-4">
<p class="font-bold text-blue-400 mb-2">ℹ️ Green 評分內核</p>
<div class="text-sm text-gray-300">

Robert 的 Green 評分**不是先看光線/天氣**,而是先看**構圖切割品質** — 比「主題豐度」「氛圍」優先級更高。

</div>
</div>


#### 30 條規則精選(v2)

**A. 評分基本面(決定星等)**
1. 場景唯一 + 合焦 + 工整 + 背景乾淨 → **3★+P**(default 保留層)
2. 沒明顯瑕疵的雷同 → 3★ default(v2 校正,不再降 2★)
3. 1★ 真正門檻嚴格:失焦 / HDR反曝光 / 主體消失 / 構圖凌亂無法後製
4. 構圖鬆 ≠ 1★(最多 2★);平光無戲劇 ≠ 1★(最多 3★)

**B. 4★ 觸發點** — 見上方「4★ Green 觸發點」

**C. 雷同擇優 — 唯一性 6 維度判斷(v2 重點 / 對應原 SKILL v2 規則 11/13/14/15)**
- 焦段 / 拍攝角度 / 拍攝視角位置 / 前景元素 / 構圖意圖 / 動態瞬間
- 任一維度顯著不同 = 獨立視覺單位 = 可獨立 P
- 必須**多維度都一致**才算「真雷同」

**真雷同擇優依據優先順序**:
1. 畫面乾淨度(無玻璃反光 / 無雨滴 / 無路人 / 無雜訊)⭐ 首要
2. 構圖切割品質
3. 動態瞬間捕捉

**D. 動態事件處理**
- 連續抽幀組裡,動態主體位置最強那張升 P,餘維持 3★
- 動態事件大組(>5 張同主題連拍)→ 整組**最多 1 張 P**
- 同場景動態主體不同動作 = 各自獨立藝術單位全升 P(小孩玩水 3 個不同動作 = 3P)

**E. 構圖與後製 — 「裁切需求度」三層級**
- 🥇 不需要裁切(主體已平衡)= 升 P 候選
- 🥈 能裁切救(小幅後製即達標)= 不扣分
- ❌ 裁切無法救(構圖凌亂)= 1★

## Pick (P) 決策公式

```
Red 4-5★  → 個別評估升 P(看是否為場景代表)
Red 3★    → 不入 P(備胎層)
Yellow 4-5★ → 升 P
Yellow 3★ → 視場景代表權決定
Green 3-5★(場景唯一 + 合焦) → 自動升 P
Purple    → 同 Green 邏輯
```

<div class="not-prose my-6 bg-red-500/10 border-l-4 border-red-500 rounded-r-lg p-4">
<p class="font-bold text-red-400 mb-2">🔴 「同場景同主角」Pick 上限</p>
<div class="text-sm text-gray-300">

同場景同主角 → **1 張 P,其餘 3★**(不是各自一色)
不可以為了「避免重複 P」就把同類照片改成不同 label 來繞過 Pick 上限。
Label 由主體決定,Pick 由場景代表權決定。

</div>
</div>

## 不可救 vs 可救(最重要的分水嶺)

| 不可救(必扣分) | 可救(不扣) |
|---|---|
| 失焦 / 主體不合焦 | 裁切偏移(後製可修) |
| 閉眼 / 半閉 | 路人入鏡(後製可修) |
| 表情僵硬 | 曝光偏差(develop 可修) |
| 笑容收攏(笑累了) | 構圖偏移(裁切可修) |
| 眼神上吊 / 疲憊 | 顏色偏差 |
| HDR 反曝光 | |

> Robert 原話:「**裁切補救=減分 不用特別扣分 還能救都是可以的 是不能救的才扣分**」

## 範例 — 同場景三張酒瓶(2026-05-10 calibration 案例)

```
場景:餐桌上酒瓶與杯子(三張連拍)
- 5354 直構酒瓶,無杯
- 5355 橫構酒瓶+杯
- 5356 直構酒瓶+杯

❌ 錯誤標法(Sonnet 幻覺):
  5354 → Purple 4P
  5355 → Purple 4P
  5356 → Green 4P  ← 因「有杯子」改 Green、又獨立 P

✅ 正確標法:
  5354 → Purple 4P  (構圖無杯獨立代表)
  5355 → Purple 4P  (構圖橫構+杯獨立代表)
  5356 → Purple 3   (構圖與 5354 重複、元素與 5355 重複 → 雷同降 3★ no-P)
```

**判斷邏輯**:
1. 主體 = 酒瓶 → 三張都 Purple(不能因杯子改 Green)
2. 5355 橫構 + 5354 無杯版,構圖差異顯著 → 各自獨立 P
3. 5356 與 5354/5355 在「構圖切割品質」維度都重複 → 真雷同 → 降 3 no-P
