# Claude Cowork 整合工作流 vs 現有環境對應

<div class="not-prose my-6 bg-red-500/10 border-l-4 border-red-500 rounded-r-lg p-4">
<p class="font-bold text-red-400 mb-2">🔴 核心結論</p>
<div class="text-sm text-gray-300">

Anthropic 旗下有兩條 Claude 產品線：Claude.ai（網頁／桌面 App）和 Claude Code（CLI）。兩條線可以**同時並存**（同一帳號、共用 Obsidian vault）。我目前的 setup 是 Claude Code + Telegram + MCP servers，已經涵蓋影片 Cowork 80% 的功能。差別在於 Claude.ai 整合度較高、Claude Code 靈活度極高。

</div>
</div>


---

## 影片介紹的 11 個 Cowork 功能

| # | 功能 | 用途 |
|---|------|------|
| 1 | CLAUDE.md 記憶檔 | 專案級長期記憶，每次自動載入 |
| 2 | Projects 專案 | 帶 Instructions 的持久上下文 |
| 3 | Scheduled 排程任務 | 固定時間自動執行（例：每週一晚 7 點做 PPT）|
| 4 | Subagents 子代理 | 並行多任務最後彙整 |
| 5 | Connectors 連接器 | 整合 Canva / Calendar / Gmail |
| 6 | Skills 技能 | SOP 說明書，被動載入 |
| 7 | Skill Creator | 用對話建立客製化 Skill |
| 8 | Plugins 外掛 | 把 Skills + Connectors 打包成工具箱 |
| 9 | 檔案管理 | 自動分類本地檔案 |
| 10 | Browser 擴充 | 操作網頁（醫院掛號示範）|
| 11 | Computer Use | 控制電腦軟體（手機遠端轉檔示範）|
| (附) | Dispatch 手機版 | 在外用手機下指令給家裡 Claude |

## 與我現有環境對應表

| 影片功能 | 我已經有的 | 對應位置 |
|---------|----------|---------|
| CLAUDE.md 記憶 | ✅ | `~/.claude/projects/-Users-james-t/memory/` |
| Projects 持久上下文 | ✅ | Claude Code + memory rules + MEMORY.md |
| Scheduled 排程 | ⚠️ 部分 | GAS 排程（股票腳本 3:30 PM），Claude 端無排程 |
| Subagents 並行 | ✅ | Task / Agent 工具 |
| Connectors | ⚠️ 部分 | Telegram + claude-in-chrome MCP，沒接 Canva/Gmail |
| Skills | ✅ | `vault/.claude/skills/`（剛裝的 5 個 obsidian skills）|
| Skill Creator | ⚠️ | 沒裝官方版，但可以手動寫 SKILL.md |
| Plugins | ⚠️ | 沒用 plugin 概念，但 telegram MCP 已是類似東西 |
| 檔案管理 | ✅ | Bash + Edit/Write/Glob/Grep |
| Browser 擴充 | ✅ | claude-in-chrome MCP |
| Computer Use | ✅ | computer-use MCP |
| Dispatch 手機 | ✅ | Telegram bot |

**結論**：核心功能已具備 80%。缺的只是 Connectors（Calendar/Gmail）和 Scheduled。

## 影片亮點值得借鏡

### 亮點 1：Skill Creator 用對話建技能

影片裡的 Claude.ai Skill Creator 是互動式建構技能，比手動寫 SKILL.md 友善。

→ 我的環境也可以做到：直接跟 Claude Code 說「幫我為 XXX 建一個 skill」我會走互動流程，最後寫成 `.claude/skills/xxx/SKILL.md`

### 亮點 2：Scheduled + Subagent 自動值勤模式

影片例子：每天早晨自動跑 3 個 subagent 找最新攝影資訊 → 彙整到資訊看板

→ 我可以設計類似的：「每天早上 8 點自動跑 3 個 subagent 看財經新聞，彙整成當日簡報推到 Telegram 股票群」

需要：
- Cron 排程（macOS launchd 或 cron）
- Subagent 並行架構
- 推送到 Telegram bot

---

## 推薦方案：混合架構

建議**保留現狀 + 加裝 Claude.ai 桌面版**（不要只走一條路）：

| 環境 | 用途 | 強項 |
|------|------|------|
| Claude Code + Telegram | 重度自動化（股票腳本、Obsidian 整理、開發工作）| 靈活、可控、可寫程式 |
| Claude.ai 桌面 App | 輕量整合（Gmail、Calendar、Canva）| OAuth 一鍵設定、整合度高 |

兩邊登入同一個 Anthropic 帳號 → 可看到同一份 vault → 互不衝突。
