## ✨ 核心功能

### 1. Text-to-Video（文字生影片）
- 從零生成，只靠文字描述
- 建議長度：**100-180 字**
- 時長：最多 **8 秒**
- 包含：視覺 + 原生音訊

### 2. Image-to-Video（圖生影片）
- 提供一張參考圖
- 用 prompt 描述**動作 + 運鏡 + 音訊**
- 建議 prompt 長度：**50-100 字**（比 text-to-video 短）
- 適合：保持角色一致性、延伸現有作品

### 3. Native Audio（原生音訊）
- 跟影片**同步生成**
- 支援：對白、音效、環境音、背景音樂
- 跟 Kling/Runway 相比是明顯優勢（他們都要後配音）

### 4. Ingredients to Video（配料生影片）⭐
- 提供多張參考圖（角色/場景/物件/風格）
- 跨鏡頭保持**視覺一致性**
- 對系列創作非常重要

### 5. First and Last Frame（首尾幀）⭐
- 給起始圖 + 結束圖
- Veo 自動生成**中間的過渡影片 + 音訊**
- 適合：轉場、連續鏡頭剪接

## 📝 Prompt 寫作 5 大元素

Google 官方建議每個強 prompt 包含：

```
Camera（運鏡）+ Subject（主體）+ Action（動作）+
Setting（場景）+ Style & Audio（風格與音訊）
```

### Text-to-Video 範例（完整版）

```
Medium shot of a woman in her 30s reading a book at a sunlit Parisian
café, warm natural light streaming through tall windows. She looks up
from her book and smiles slightly, noticing someone off-camera. Relaxed
morning atmosphere, contemporary lifestyle photography.

Audio: Gentle café ambience — quiet conversation, espresso machine hiss,
light jazz in background.
```

分解：
- **Camera**: Medium shot
- **Subject**: woman in her 30s reading a book
- **Action**: looks up from her book and smiles slightly
- **Setting**: sunlit Parisian café, warm natural light through tall windows
- **Style**: contemporary lifestyle photography, relaxed morning atmosphere
- **Audio**: café ambience + espresso machine + light jazz

### Image-to-Video 範例（精簡版）

```
Static camera. The woman blinks naturally once, then smiles subtly.
Steam rises from the coffee cup. Light breeze moves her hair.

Audio: soft café ambience, gentle clinking of a cup.
```

只描述**動作 + 運鏡 + 音訊**，人物外觀由參考圖決定。

## 🎵 音訊生成進階語法

### 對白（用引號）
```
"A woman says, 'We have to leave now.'"
```

### 音效（用 SFX:）
```
SFX: thunder cracks in the distance
SFX: footsteps on wet pavement
```

### 環境音（用 Ambient:）
```
Ambient: quiet hum of a starship bridge
Ambient: distant city traffic, birds chirping
```

### 背景音樂（用 Music:）
```
Music: melancholic piano melody in minor key
Music: upbeat indie pop with acoustic guitar
```

## 🎯 視覺一致性的 3 大技巧

### 1. 在每個 prompt 重複主角特徵
如果角色是「warm brown updo, pink floral kanzashi, black furisode with crimson florals」，**每個鏡頭都要寫一次**，不能只寫一次後面省略。

### 2. 用 Ingredients to Video
上傳角色參考圖 + 場景參考圖 + 風格參考圖，Veo 會自動保持一致。

### 3. 用 First-Last Frame 銜接
鏡頭 A 的最後一幀 = 鏡頭 B 的第一幀 → 無縫接軌。

我們已經裝了 universal-video-prompt skill（八層漢堡公式）。跟 Veo 的 5 元素可以這樣對應：

| Veo 5 元素 | universal-video-prompt 八層 |
|-----------|-----------------------------|
| Camera | Medium + Shot Type + Angle + Movement + Focus |
| Subject | Subject |
| Action | Subject 層的動作描述 |
| Setting | 隱含在 Subject 或 Lighting |
| Style & Audio | Lighting + Color + Audio |

→ **八層公式已經涵蓋 Veo 需要的 5 元素**，直接用 skill 產出的 prompt 餵 Veo 即可！

### 完整流程建議

```
1. 用 universal-video-prompt skill 寫八層架構 prompt
   → 直接貼給我「幫我用 universal-video-prompt 寫一個 XXX」

2. skill 會產出：
   - 完整英文 prompt

3. 打開 Google Flow（或 Gemini App）

4. 貼入 Veo3 版本 prompt
```

## 🆚 Veo3 vs Kling 對比

| 項目 | Veo 3.1 | Kling AI |
|------|---------|---------|
| 免費額度 | **50-180 credits/天** | 較少 |
| 最大時長 | 8 秒/次 | 5-10 秒/次 |
| 原生音訊 | ✅ 強項 | ❌ 要後配 |
| Image-to-video | ✅ | ✅ |
| 運鏡控制 | 透過文字 | 有 UI 選項 |
| 人物質感 | 極強 | 強 |
| 中文 prompt | 支援但英文較好 | 對中文友善 |
| 亞洲風格（和服、東方）| 中等 | 強（中國團隊開發）|
| 寫實日常 | 極強 | 強 |
| 運動/動作戲 | 強 | 強 |
| 整合生態 | Google 全家桶 | 獨立 |
| 定價 | $7.99/月起 | 免費試用 + 訂閱 |

### 選擇建議

- **想要最高品質 + 原生音訊** → Veo 3.1
- **想要中文介面 + 亞洲風格** → Kling
- **預算超緊** → Veo 3.1 免費額度（Google Flow）
- **商業大量生產** → Veo API（最便宜 $0.15/秒）
- **運鏡控制要細** → Kling（有專門的運鏡 UI）

最佳實務：**兩個都用**，不同場景選不同工具。

## 🎬 適用場景

### Veo 3.1 最擅長
- 寫實日常場景（咖啡店、辦公室、街景）
- 對話戲（原生音訊含台詞）
- 商業廣告（高品質 + 音訊一次出）
- 教學短片（Gemini 直接調用）
- 首尾幀轉場（做連續鏡頭）

### Veo 3.1 相對弱的
- 極端想像場景（超現實、奇幻）
- 亞洲文化細節（不如 Kling 準）
- 長影片（最多 8 秒/次，要剪接）
- 精細的運鏡操控（文字描述 vs UI 選單）

## ⚠️ 已知限制

1. **單次 8 秒上限** — 要做長片需要多個鏡頭剪接
2. **不能生成真實名人** — 安全限制
3. **文字渲染不穩** — 有字幕的場景可能失真
4. **版權疑慮** — 商用要看訂閱方案條款
5. **中文 prompt 效果較弱** — 英文 prompt 產出較穩
