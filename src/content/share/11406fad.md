# 產出自動分場景 · export-auto-move

出片工具：把 LR 匯出的成品 JPG，依母檔所在的 day／場景，**自動分天分場景**鏡射到 `_export`。**catalog-free**（A 方案，中繼資料已烤進 JPG，不碰 LR catalog）。James 2026-07-01 命名並拍板結構。

## 流程
`LR 匯出成品 JPG` → `<trip>/to_export/` → `export-auto-move` → `<trip>/_export/<dayN 資料夾>/<場景>/`

## 邏輯
1. 用**檔名（去副檔名）當鑰匙**，掃 trip 各 day 的 `主/次/<場景>/` 母檔，建「stem → (day, 場景)」對照表。
2. `to_export/` 每張成品 JPG，鏡射到母檔對應的 `_export/<day 資料夾>/<場景>/`。
3. 結構（James 拍板）：**① 分天**（每 dayN 一夾）　**② 主/次合併**（OPPO 與第二台同一場景夾）。

## 用法
```
export-auto-move "<trip 根目錄>"          # dry-run 先看每 day/場景張數
export-auto-move "<trip 根目錄>" --go     # 確認後實搬
# 別名 to_export 亦可；可 --to_export / --export 自訂來源與輸出夾
```

## 自動偵測 / 兼容結構（2026-07-01 巴黎實戰補強）
- **單日 trip**：母檔在 `<trip>/主(次)/<場景>/`（沒有 dayN 層）→ 自動偵測，`_export/<場景>/` 攤平不分天。
- **多日 trip**：`<trip>/<dayN>/主(次)/<場景>/` → `_export/<dayN>/<場景>/` 分天。
- **Evoto round-trip**：`-EVT`／`-EVTO` 成品尾綴自動 strip → Evoto 版對得上母檔。
- **`--ext jpg`**：只搬指定副檔名（排除 to_evoto 裡的 `.tif` 送洗中間檔）。

## 規則 / 前提
- LR Export 檔名選**「原始檔名」**，成品 stem 才對得上母檔（`RKLU8425.jpg` ↔ `RKLU8425.DNG`）。
- 尾綴自動 strip 再比對：`-2` `-Edit` `-Enhanced` `-NR` `-HDR` `-Pano` `-Denoise` `-Copy` `-EVT` `-EVTO`；但母檔真實的 `_01` 尾**保留**不誤刪。
- 對不上（找不到母檔）→ **列清單、留在 to_export/**，不亂搬。
- 同名衝突（stem 對多場景）報告標 ⚠️（trip 內檔名通常唯一，0 衝突）。
- 🔒 鐵則：先 dry-run 看鏡射預覽，再 `--go`。

## 實測
德國 5天4夜：母檔 1032 張、stem 全唯一、0 場景衝突；`-2`/`-Edit`/`-Enhanced-NR` strip 正確、`_01` 保留、`NOMATCH` 正確留置。
