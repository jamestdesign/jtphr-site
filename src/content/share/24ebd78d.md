| Repo | 特色 | 工具數 |

| **jordanl61/premiere-pro-mcp-server** | 較新實作 | — |
| **helloprkr/mcp-adobe-cloud** | 含 Lightroom + Premiere + AE | — |

### Premiere Claude 能做什麼

- **媒體管理**：匯入素材 / 整理 bin / 批次重新命名
- **時間軸操作**：切片 / 拼接 / 自動同步音訊 / **移除靜音段** / 批次刪 NG
- **效果與轉場**：套用 LUT / 動態圖形 / 字幕標題
- **音訊**：自動降噪 / 對話增強 / **去 filler words（呃、嗯）**
- **色彩校正**：Auto color / LUT 套用 / 白平衡
- **匯出**：H.264 / ProRes / IG / TikTok 預設

### 安裝（hetpatel-11 版）

```bash
git clone https://github.com/hetpatel-11/Adobe_Premiere_Pro_MCP.git
cd Adobe_Premiere_Pro_MCP
npm install && npm run build && npm run setup:mac
```

然後 Premiere → 偏好 → 啟用 UXP Plugins developer mode → Window → Extensions → MCP Bridge (CEP)

## 🍎 2. Apple Final Cut Pro X (FCPX) MCP

### Top GitHub Repos

| Repo | 特色 | 工具數 |
|------|------|--------|
| ⭐ **DareDev256/fcpxml-mcp-server** | 第一個 FCPX MCP，FCPXML 為基礎 | 53 |
| **elliotttate/finalcutpro-mcp** | 用 AppleScript + JXA 自動化 | ~100 |
| **SpliceKit** | 給 Claude Code / ChatGPT 完整 FCPX 控制 | — |

### FCPX MCP 的特性

跟 Premiere MCP 不一樣，FCPX 的 MCP 走的是 **FCPXML 路線**：
- 把 FCPX 的時間軸**匯出成 XML**
- AI 讀 XML，分析 / 修改 / 重組
- 結果**匯入回 FCPX**

這個架構的優缺點：

✅ **優點**
- FCPXML 是 Apple 的官方標準，穩定
- AI 處理結構化資料（XML），準確度高
- 不需要 Premiere 那種 CEP 擴充
- 工作流可以離線跑

❌ **缺點**
- 不是即時操控（要 export → AI → import）
- 部分功能無法用 XML 表達（特殊效果、外掛）
- 需要學 FCPXML 結構

### FCPX Claude 能做什麼

- **時間軸分析**：統計切點數量、clip 時長
- **抽取 markers**：把所有 marker 列出來
- **生成編輯清單**：edit list / EDL
- **修改專案**：加 markers、重排 clips
- **AI 剪輯建議**：基於節奏分析建議切點
- **批次處理**：對多個專案執行同樣編輯

### 安裝（DareDev256 版）

```bash
git clone https://github.com/DareDev256/fcpxml-mcp-server.git
cd fcpxml-mcp-server
npm install && npm run build
# 註冊到 Claude Code 的 mcp config
```

工作流：
1. FCPX 中：File → Export XML
2. 跟 Claude 說：「分析這個 fcpxml 並建議剪輯」
3. Claude 修改 XML
4. FCPX 中：File → Import XML

### SpliceKit（值得特別提）
- 網址：https://splicekit.fcp.cafe/
- **免費**，給 Claude Code / ChatGPT 完整 FCPX 控制
- 是 fcp.cafe 社群的官方專案
- 自動化程度比 DareDev256 更高

## 📱 3. CapCut MCP

### Top GitHub Repos

| Repo | 特色 |
|------|------|
| ⭐ **mrbuslov/capcut-ai-editor** | 自動處理「talking head」影片，去靜音、找重複 take、加字幕 |
| **atx-guy/capcut-mcp-server** | 11 個 CapCut Pro 專業工具 |
| **fancyboi999/capcut-mcp**（CapCutAPI）| HTTP API + MCP 整合 |
| **sun-guannan/VectCutAPI** | 開源的 CapCut API 替代品 |

### CapCut MCP 的特性

CapCut MCP 走的是**草稿檔（draft file）操作**路線：
- 讀取 / 修改 / 儲存 CapCut 的 draft 檔
- 不需要 CapCut 的 API key（heuristic 本地處理）
- **行動端 + 桌面端**都能用

### CapCut Claude 能做什麼

#### mrbuslov 版（talking head 自動化）
- **讀取 CapCut 自動生成的字幕**
- 找出靜音段並自動移除
- 偵測重複 take（NG 重拍）並自動刪除
- 直接在 CapCut 專案上完成編輯
- **不需要 API key**，純本地處理

#### atx-guy 版（11 工具完整套件）
- 影片素材管理
- 時間軸操作
- 字幕生成
- 特效套用
- 匯出設定

#### CapCutAPI 版
- HTTP API 介面（可整合到自家系統）
- 草稿檔的完整 CRUD
- 支援影片 / 音訊 / 圖片 / 文字 / 特效

### 安裝（mrbuslov 版）

```bash
git clone https://github.com/mrbuslov/capcut-ai-editor.git
cd capcut-ai-editor
npm install && npm run build
# 註冊到 Claude Code MCP config
```

## 📊 三大平台深度對比

### 自動化程度

| 任務 | Premiere | FCPX | CapCut |
|------|---------|------|--------|
| 移除靜音段 | ✅ 即時 | ✅ via XML | ✅ 即時 |
| 去 filler words | ✅ | ✅ via XML | ⚠️ 需要字幕分析 |
| 自動同步音軌 | ✅ | ✅ via XML | ⚠️ 部分支援 |
| 批次刪 NG take | ✅ | ✅ | ✅ |
| 動態圖形 | ✅（有限）| ⚠️ | ⚠️ |
| 自動 LUT / 色彩 | ✅ | ✅ | ✅ |
| 自動字幕 | ⚠️ 需 transcribe | ⚠️ | ✅ 內建很強 |
| 多軌音訊 | ✅ | ✅ | ⚠️ |
| 即時操控 | ✅（CEP）| ❌ XML 出入 | ✅ draft 操作 |
| 可程式化 | ✅ | ✅ | ✅ |

### 你需要付什麼

| 平台 | 成本 |
|------|------|
| Premiere Pro | NT$700/月（單品 Creative Cloud）|
| Final Cut Pro | NT$9,000 一次買斷（或學生 NT$6,300）|
| CapCut | **免費**（基本功能）/ Pro $7.99/月 |

### 學習曲線

| 平台 | 難度 |
|------|------|
| Premiere | 中-高（介面複雜但業界標準）|
| FCPX | 低-中（Apple 設計，直覺）|
| CapCut | 低（行動 UI，模板多）|

### 適合的人

| 平台 | 適合 |
|------|------|
| **Premiere + MCP** | 已經是專業剪輯師、有 Adobe 訂閱、做 YouTube 長片 |
| **FCPX + MCP** | Mac 用戶、學生、買斷不喜訂閱、做高質感短中片 |
| **CapCut + MCP** | 沒預算、做 IG/TikTok 短片、新手 |

## 💡 我給你（用戶）的建議

### 排序建議（依你目前情況）

#### 🥇 第一推薦：**CapCut + mrbuslov MCP**（門檻最低）
- **免費**，你今天就能裝
- 行動 + 桌面都能用
- 適合做股票分析的短影片（IG Reels / TikTok）
- mrbuslov 版內建「移除靜音 + 去重複 take」是製作說明影片的剛需
- **無痛試水溫**

#### 🥈 第二推薦：**Final Cut Pro + SpliceKit**（性價比最高）
- 一次買斷 NT$9,000，**沒有月費**
- Apple 原生，Mac 用戶的最佳剪輯軟體
- SpliceKit 是社群免費 MCP，跟 Claude Code 對接好
- 適合：你之後常做股票影片，不想被 Adobe 月費綁
- 缺點：需要先投入買斷

#### 🥉 第三推薦：**Premiere Pro + hetpatel MCP**（功能最強）
- 訂閱 NT$700/月（持續成本最高）
- 但工具數最多（269 個），完整自動化程度最高
- 適合：你已經有 Adobe 訂閱，或做高頻內容生產

## 🔮 終極流水線設想（不限平台）

不論選哪個平台，最終你可以建立的自動化流水線：

```
[資料來源]
盤後分析 / 股票新聞 / 影片連結
        ↓
[Claude Code 處理]
摘要 + 結構化 + 寫稿
        ↓
[ig-card-generator skill]
產出 IG 圖文 PNG（你已有）
        ↓
[圖生影片 - Veo 3.1 / Kling]
靜態圖 → 動態影片片段（你已有 prompt skills）
```
