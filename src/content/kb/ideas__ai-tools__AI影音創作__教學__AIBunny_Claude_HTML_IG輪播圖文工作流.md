# AI Bunny — 用 Claude 做 IG 輪播圖文（HTML 卡片 + 截圖工作流）

> [!important] 一句話結論
> 不用 Canva、不用 PS。用 Claude **寫 HTML 卡片 + 自動截圖**，可以一句話產出**整套 IG 輪播圖文**（5-7 張）+ 高清 PNG（1320×1650）。秘密武器是一份 **SKILL.md 設定檔**，記住你的品牌風格，以後每篇都自動統一。從 1 小時縮短到 5 分鐘。

## 🎯 核心觀念

### 工作原理（HOW IT WORKS）

```
你說「幫我做圖文」
        ↓
Claude 寫 HTML 卡片（用你預設的品牌風格）
        ↓
自動截圖匯出 PNG（1320×1650）
```

**這個流程的關鍵是「不用設計軟體」**：
- ❌ 不用 Canva
- ❌ 不用 Photoshop
- ❌ 不用 Figma
- ✅ Claude 直接寫 HTML/CSS → 用瀏覽器截圖匯出

### 秘密武器：SKILL.md 設定檔

> 一份 .md 文字檔，寫好配色、字體、排版規格
> Claude 讀了就知道怎麼做你的品牌風格
> 像是幫 AI 設計師寫的品牌手冊

這個 SKILL.md 包含：
- 主色 / 次色 / 強調色（HEX 色碼）
- 字體選擇與大小
- 排版規格（邊距、欄寬、行距）
- 圖文卡片的版型結構
- 風格範例（深色科技 / 淺色科技 / 手繪風 / 雜誌風...）

### 怎麼附加 SKILL

1. **Claude Chat / Cowork 都可以**
2. 加到 **Project** 裡 → 以後說關鍵字就**自動觸發**
3. 或是每次對話按 **+ 附加**

### 風格切換

Skill 內建至少 2 種風格：
- **深色科技**（dark tech）
- **淺色科技**（light tech）

說「**淺色版**」就自動切換，或把色碼改成你的品牌色。

## 🎯 為什麼這個工作流值得學

雖然你不一定要做 IG 經營，但「**讓 Claude 寫 HTML + 自動截圖**」這個思路可以延伸到：

1. **股票分析報告** → Claude 寫 HTML 卡片 → 截圖發到 Telegram 股票群
2. **筆記摘要** → Obsidian 筆記轉成漂亮的視覺化卡片
3. **個股 AE 強弱信號儀表板** → HTML 動態渲染 → 截圖存檔
4. **每日 session insight** → 從文字筆記轉成可分享的圖片

這個技巧叫做「**HTML-to-image with AI**」，是一個被低估的工作流。
