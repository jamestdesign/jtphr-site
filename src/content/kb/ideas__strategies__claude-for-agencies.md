# Claude for Agencies — 最高 ROI 工作流程

> 來源：@mobileeditingclub（Instagram）
> 日期：2026-04-05
> 類別：商業策略 / 內容行銷

## 一句話摘要
代理商用 Claude 自動化內容生產，交付更快、pitch 更好、不需擴編人力。

## 四大高 ROI 工作流程

### 1. 自動填滿社群媒體月曆
- 輸入：品牌守則 + 社群策略
- 輸出：貼文概念 + 文案 + 腳本

### 2. 一份簡報 → 完整 Campaign
- 輸入：客戶 brief
- 輸出：漏斗策略 + 創意方向 + 圖片 + 剪輯指引

### 3. 自動建立品牌守則文件
- 分析客戶定位、市場、受眾 → 輸出品牌參考文件

### 4. 跨平台內容再利用
- 一篇核心內容 → LinkedIn / IG / YouTube 各自原生格式

## 行動建議
先建立個人/品牌守則模板，之後所有內容請 Claude 生成時引用。
