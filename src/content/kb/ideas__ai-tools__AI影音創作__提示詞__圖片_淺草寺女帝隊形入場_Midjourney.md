## 視覺分析（依實際照片）

### 人物特徵
- 20 出頭日本年輕女性
- 圓潤臉型、五官精緻、白皙肌膚
- **棕褐色染髮**（不是純黑），有瀏海

- **配色**：深紅 + 朱紅 + 金 + 淺粉 + 白

- **腰繩**：粉色裝飾繩（obi-jime）
- **足袋 + 木屐**：白足袋 + 黑色塗漆木屐

## 五層架構拆解

### 🎯 Subject（主體）
- **中心**：和服女帝（依照片校正描述）
- **環繞**：12+ 名黑西裝保鏢，**楔形隊形**
- 保鏢服裝：合身黑西裝 + 白襯衫 + 黑領帶 + 太陽眼鏡 + 統一造型
- **構圖原理**：楔形指向中央 → 視覺漏斗引導到女子身上

### 🏞️ Scene（場景）
- 淺草寺雷門入口，朝鏡頭方向前進
- **前景**：保鏢（柔焦 → 銳利漸層）
- **中景**：女子 + 核心隊形
- **後景**：雷門紅燈籠 + 寺廟建築
- **氛圍**：青銅香爐煙霧

### 💡 Lighting（光線）
- 黃金時段晚期戲劇光
- **背後逆光輪廓光**（rim light from behind）→ 所有人物金邊
- **長影子投射** → 時間感與儀式感
- 石板路上的長影是電影級元素

### 🎨 Style（風格）
- editorial cinematography
- 參考風格：**日本政治劇開場** + **現代黑幫片入場**
- **高對比色盤**：
  - 和服黑+花樣（主角）
  - 保鏢純黑
  - 雷門朱紅
  - 暖琥珀陽光
  - 冷藍地面陰影

### 📷 Technical（技術）
- **24mm 廣角**（容納整個隊形）
- **deep focus 全域對焦**（關鍵差異：跟單人 prompt 的淺景深相反）
- 微仰角（slight low angle）
- 8K ultra detailed, no motion blur

🖼️ **超寬電影級 still**：

- 中心：女子站在楔形中央，黑底花卉和服搶眼

適合用途：廣告主視覺、電影海報、IG 封面、短片開場

## 平台建議

### 首推：Midjourney v6.1 + character reference

```
[上面完整 prompt] --ar 21:9 --s 500 --c 8 --cref [照片URL] --cw 80
```

- `--ar 21:9` 電影級超寬比例
- `--s 500` 風格化強
- `--c 8` 中等變化（避免完全一樣）
- `--cref` = character reference（鎖定角色臉型）
- `--cw 80` = 80% 人臉相似度

### 次選：Flux 1.1 Pro + LoRA

- 用參考照片訓練個人 LoRA（需要 3-5 張）
- 一致性極高但需要技術門檻

### 第三：DALL-E 3

- 不支援 character reference
- 只能用文字描述，臉會不一致
- 優點：免操作

## 變體建議

### A：時間變體 — 雨後夜晚
換成夜晚場景：路面濕滑反射雷門紅光與燈籠光，更黑幫片風格。加入：
```
rain-soaked stone path reflecting vermilion lantern light,
neon-like reflections, night scene with practical lanterns
```

### B：構圖變體 — 環繞鏡頭
從靜態寬景改成動態 orbit。保鏢隊形依然楔形，但觀察角度環繞 90 度。

### C：季節變體 — 雪中入場
```
snow falling gently, breath visible in cold air,
snowflakes catching the warm light from the lanterns,
cool blue shadows on pristine white snow
```
