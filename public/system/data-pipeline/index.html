watchlist 翻紅

score = Z近4週提及(0~4) + 月漲(−2~+2) + 週漲(−1~+1) + 24週位置(−1~+1) + 法人買賣超(−1~+1)

⑨關鍵踩坑與根治

坑根治
macOS FDA/TCC：launchd 子程序無權限 → 自動發佈靜默失敗給 /usr/bin/python3 完整磁碟取用權，子程序繼承
認證誤標：反覆起停讓 telegram plugin 被當壞跳過啟動前清 mcp-needs-auth-cache.json
Apps Script 6 分鐘上限：126 檔逐格寫入超時改本機 Python 平行抓取 + 批次 POST；GAS 只留輕量 doPost
TWSE 單位誤判：法人數值是「股」不是「千股」全部 ÷1000 換算成張
TPEX JSON 端點失效改 CSV 下載端點 + Big5 解碼
Web App % 字元：URL 編碼造成解碼失敗寫入前剔除文字內 %
