🎛️ 出片指令
指令名稱：grid　或打　拼貼輸出
用法 = 樣式 + 格式 + 色調 + 標題 + 內文。把照片丟進 to_grid/，給參數就出圖到 to_grid/_out/。 
grid <照片夾> --style 壁貼 --format 直式 --tone 暖 --title "Le Train Bleu" --text "Paris · 2026"
參數可選值
樣式 style馬賽克　/　壁貼　/　剪貼簿　/　剪貼簿黑
格式 format方形　/　直式　/　長版　/　橫式　/　all（一次出四種）
色調 tone原色　/　黑白　/　暖　/　冷　/　莫蘭迪
標題 title大標（壁貼用草寫、剪貼簿用大寫）
內文 text副標 / 小字（如日期、地點）
📐 格式 format 對應比例
格式解析度比例用途
方形1080 × 10801:1IG 貼文
直式1080 × 19209:16IG 限動 / Reels / TikTok
長版1080 × 16202:3Pinterest / IG 直式貼文
橫式1920 × 108016:9YouTube / FB 封面 / 橫向
all以上四種一次出—一次備好各平台
💡 一張拼貼甜蜜點 5–7 張、上限約 9 張（方形/橫式 4–7，直式/長版 6–9），超過自動拆多張。

🅰️ 馬賽克格狀 — 乾淨雜誌感,適合食物/家飾/物件

不規則矩形格 + 留白 + 圓角,大小交錯。前 4 張同組照片換色調;後 3 張換格式(比例)。

🅱️ 壁貼 — 優雅留白 + 草寫標題,適合旅遊/封面

乾淨照片(細白框)+ 中央草寫標題 + 淺色留白。※ 花/蝶壓邊貼紙待素材庫,這版先呈現版型+標題。

🆑 剪貼簿 / 手帳 — 拍立得白框 + 旋轉疊放 + 手寫 + 塗鴉

隨性回憶感。剪貼簿=淺底(手寫地名、愛心)；剪貼簿黑=黑底直排(上下標題,Story 風)。
