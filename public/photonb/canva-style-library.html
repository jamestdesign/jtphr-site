🖼️ to_canva 拼貼風格資料庫

v0.1 草稿 · 2026-06-28 · 全部由現有歸檔照片「程式全自動」產出（0 Canva）
怎麼用:你把要拼的照片丟進 to_grid/ → 我自動同色系分組(每組約 6 張) → 套風格版型 → 出多種比例與色調 → 完成。
比例:方形 / 直式 / 長版 / 橫式 色調:原色·同色系 / ⚫黑白 / 🟠暖 / 🔵冷 / 🤍莫蘭迪 字型:系統內建(草寫 Snell / 手寫 Bradley / 標題 Futura·Didot)
下面三大風格,每張都是不同版型 × 色調 × 比例的範例,給你挑。

🅰️ 馬賽克格狀 — 乾淨雜誌感,適合食物/家飾/物件

不規則矩形格 + 留白 + 圓角,大小交錯。下面前 4 張同一組照片、換色調;後 3 張換比例。

🅱️ 壁貼 — 優雅留白 + 草寫標題,適合旅遊/封面

乾淨照片(細白框)+ 中央草寫標題 + 淺色留白。※ 花/蝶壓邊貼紙待素材庫,這版先呈現版型+標題。

🆑 剪貼簿 / 手帳 — 拍立得白框 + 旋轉疊放 + 手寫 + 塗鴉

隨性回憶感。兩種變體:① 堆疊 pile(淺底、手寫地名、手繪愛心) ② 黑底直排(上下標題,Story 風)。

🎞️ 影片馬賽克 — 多支影片同時播放的動態拼貼

用 ffmpeg 把多支 clip 合成一張「會動的拼貼」,同時播放,輸出一支 mp4。下面是 4 支巴黎風景片 2×2 動態馬賽克(方形 8 秒,靜音)。可加背景音樂、出各比例。
