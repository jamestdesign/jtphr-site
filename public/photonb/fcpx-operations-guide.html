③ Generate Captions Mac + iPad

用途：自動把片中語音轉成字幕，直接排進時間軸，字型／顏色／位置／動畫樣式都能調。（延續 FCP 11 的 Transcribe to Captions，這次 AI 更準、更自動。）

怎麼操作：

  1. 時間軸選有語音的 clip（或整段時間軸）
  2. 觸發 Generate Captions（從 字幕/Captions 選單；報導的快捷鍵為 Shift+Cmd+C）
  3. AI 轉錄 → 產生 caption 層 → 在 Caption 檢視器/Inspector 校正文字、改樣式（字型/色/位置/動畫）
🔥 接你流程：這正是攝影區代辦「影片對話字幕/角色辨識專案」的官方解。家庭對話片直接自動上字幕，你只校正少數人名／錯字。語者分段（誰在講）仍可搭 Whisper 前處理或手動指派，字幕層本身讓 FCP 自動生。
💡 先驗準度：拿一支有國/台語混講的片試，看繁中轉錄準不準，再決定要不要全趟批次上。

④ Edit Detection Mac + iPad

用途：把一支「已經壓平的成品影片」自動拆回原本的一段一段 clip 到時間軸——不用你手動找切點。

怎麼操作：

  1. 把成品檔（例：一支已輸出的 mp4）拉進時間軸
  2. 觸發 Edit Detection
  3. AI 分析畫面切點 → 自動在每個原切點斷開成獨立 clip

接你流程：手上只剩輸出檔、沒有原專案時，要改片／重剪／擷取精華段做社群短片，靠這個免手動一格一格找切點。

⑤ Auto Mask ＋ Magnetic Mask Mac only

用途：把畫面裡的特定元素單獨圈出來（做遮罩），配合調色或特效只作用在那個區域。兩個是一組：

Auto Mask（自動）

  1. 對 clip 套 Auto Mask
  2. 把游標 hover 在畫面上 → 即時預覽 AI 偵測到的主體
  3. 從 Inspector 的清單勾選要遮的元素：皮膚 / 頭髮 / 天空 / 植物 / 衣服
  4. 接上色彩校正或效果 → 只作用在那個遮罩區

Magnetic Mask（手動精修）

Auto Mask 的手控版：拖到 clip 上 → 用滴管點你要的主體 → 它追蹤 → 完全由你決定辨識/追蹤/遮什麼。當 Auto Mask 自動抓不準時用。

接你流程：天空單獨壓藍加對比、人物膚色單獨修、植物單獨加飽和——免像以前手動一格一格描邊。

⑥ Match Color（重做版）Mac only

用途：跨鏡頭自動校色——把一個鏡頭的色調套到另一個上，這次重做過，更廣的素材與光線條件都能配得更自然。

怎麼操作：

  1. 選要被校色的 clip
  2. 用 Match Color → 指定一個參考影格（reference frame）（你想要的目標色調那一格）
  3. FCP 分析兩者 → 自動套色 → 再手動微調
接你流程：你多機拍（OPPO / iPhone / Sony）同一場景色調對不齊 → 挑一支當基準，其他一鍵拉齊；黃金時刻連拍統一色溫。

⑦ Advanced Trimming Mac only

用途：入點／出點一格一格微調，做到單格精準。

怎麼操作：trim 一段時，用逐格控制細修入/出影格，不再只能大略拖。

接你流程：剪輯精修階段對音樂節奏卡切點、修掉頭尾多一格的瑕疵。

⑧ 送 Pixelmator Pro Mac only

用途：把時間軸上某一影格送進 Pixelmator Pro 修（做縮圖、社群封面圖），改完自動整合回時間軸。

怎麼操作：選/右鍵某影格 → 送 Pixelmator Pro → 編輯 → 存檔自動回到 FCP 時間軸。

接你流程：出 YouTube 縮圖 / IG 封面，不用另外截圖再開別的軟體。

⑨ 這些我能幫你批次自動跑

上面是你在 FCP 內手動點的做法。其中可自動化的，我能透過 SpliceKit（程式化操控 FCP）幫你整趟批次跑，不用一支一支手動：

  • 整趟對話片 一次全上字幕（Generate Captions 批次）
  • 同場景多機片 批次校色（挑基準後套整組）
  • 撿片後 批次抽 KP 幀出圖（既有流程）
💡 用法：素材備好跟我說「整趟上字幕」或「這場多機校色」，我用 SpliceKit 跑完再回你結果，你只做最後校正。
