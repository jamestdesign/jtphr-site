🗺️ 影片端六步（A → F）

一趟旅遊的影片從倒卡到成片。每格標誰做、用哪支工具；工具細節點連結。

歸檔・建工作檔Robert

暫存區倒卡 → 時區校正 → 分天分場景 → 影片進 MOV_<day>/<場景>/ → 鋪好 LR catalog 與空的 FCP 庫。

ir_tag 同時跑：切分鏡、標 內容／景別／品質／建議HL 關鍵字。scene_build 工具頁 →

建庫・一次匯入 FCPRobert

leave-in-place，母帶不複製。你開庫就能撿。trip-fcpx-build 工具頁 →

Phase C 撿片，你手上的順序

  1. 開庫 → 先用關鍵字篩：建議HL 看一遍，同意就打 ★4；品質:不可用 一次排除；景別:特寫＋場景 直接做 ★2 拼貼。
  2. 逐支看：整支或框範圍 → Ctrl+1~5 打星等（同一段可同時有 ★3 與 ★4，★4 是裡面的精華點）。
  3. 看到好單禎：I 再 O（不動 playhead）→ 打關鍵字 KP。
  4. 看到壞段：框範圍 → Delete。
  5. 全部撿完 → 檔案 › 輸出 XML → .fcpxmld 丟給我。
💡 星等是你的判斷，我不污染。我只寫關鍵字（內容／景別／品質／建議HL），星等一律你打。VLM 給的分只當參考，不自動篩。

📁 資料夾結構（兩個世界，現行）

<trip>/
├── day1 …/<NN_HHMM_場景>/          ← 照片場景（ARW／DNG／JPG）＝ LR 世界
├── _<trip>_LR/<trip>.lrcat          ← LR catalog（照片管理器）
├── _preview_mov_KP/<場景>/            ← KP 單禎 JPG（D 出的，寫回 LR 用）
├── _preview_mov_HL/<場景>/            ← HL 短片 mp4（雲端相簿觀賞）
├── to_export/  to_evoto/  to_montage/  ← 落地區：一律頂層，跑完應為空
├── _export/<day>/<場景>/              ← 照片＋HL 成品（上雲端）
└── _<trip>_創作/                     ← 影片／創作世界（整夾拷 NAS，不寫回 LR）
    ├── <trip>.fcpbundle               ← FCP 庫（leave-in-place，只記引用；收尾可刪）
    ├── <day>.fcpxmld                  ← 撿片／剪輯事實（要備份的那個）
    ├── MOV_<day>/<場景>/<clip>.MOV     ← 影片母帶，唯一一份，永遠不切
    └── _montage/<day>/<場景>/         ← 進片照片（to_montage 鏡射來，長邊 5760）
兩句話管到底：to_ 開頭＝落地區（東西丟進去，一律 trip 頂層，跑完應該是空的）；_ 開頭＝成品（分好 day／場景，各回各家）。to_export 空＝已經處理完，不是沒跑過。
💡 to_montage 為什麼存在：照片的管理器是 LR，LR 不管影片，所以照片要跨進影片世界需要一個中繼站；門檻＝LR ★4／★5＋這支片要用的場景。影片不需要中繼站，FCP 就是它的管理器，選片事實只在 .fcpxmld。雲端那份 _export 長邊只有 4000，推移一放就糊，所以 to_montage 另出 5760。

③ 交件：輸出 XML

  1. 側欄選中 Event（不是 Project、不是 Library 最上層）。
  2. 檔案 › 輸出 XML… → Metadata view 選 General 或 All → 版本選最新（1.10 以上）。
  3. 存成 <day>.fcpxmld，放在 _<trip>_創作/ 跟庫同層 → 路徑丟給我。
💡 一次 export 驅動全部：★ 關鍵字＋KP＋Reject 全在同一個 XML 裡，我一支腳本全跑；不用分 KP 給一次、HL 給一次。每次 export 是當下快照，中途又改了標記就再 export。.fcpxmld 是套件（右鍵「顯示套件內容」看得到 Info.fcpxml），.fcpxml 是純文字，我兩種都吃。

④ 維運

搬 NAS 後 reconnect

  1. FCPX 關閉 → 整個 trip 資料夾原樣搬（_<trip>_創作/ 整夾）。
  2. 從 NAS 開 .fcpbundle → 跳「missing files」→ 點 Locate All… → 指 NAS 上的 MOV_ 母夾，全部自動重連。
🚨 FCPX 記絕對路徑。關鍵是 MOV_ 跟庫的相對結構不變；搬完別改 MOV_ 的名字，否則要逐支重連。

Library 瘦身（30–70%）

選中 Library → 檔案 › Delete Generated Library Files… → 勾 Render／Optimized／Proxy → Delete。只清衍生暫存，Keyword／Favorite／Marker／Timeline 100% 保留。時機：出完片要搬 NAS 前、庫超過 50GB、季度封存。

收尾保存

只留 MOV_<day> 原檔＋最新 .fcpxmld；.fcpbundle 刪掉（荷蘭實測 1.5 MB vs 283 GB）。刪前三步：確認 .fcpxmld 是最新 → 確認素材是 leave-in-place → 刪完先匯回一次確認打得開。

💡 先玩這三個最有感：Generate Captions（拿一支對話片試）、Match Color（兩台相機同場景）、Auto Mask（想單調天空的片）。

Generate Captions 自動字幕

  1. 時間軸選有語音的 clip（或整段）。
  2. 字幕選單 › Generate Captions（報導的快捷鍵 Shift+Cmd+C）。
  3. 產生 caption 層 → 在 Caption 檢視器校正文字、改字型／顏色／位置／動畫。

家庭對話片直接自動上字幕，你只校正人名／錯字。語者分段（誰在講）可搭 Whisper 前處理或手動指派。先拿一支國／台語混講的片驗準度，再決定要不要全趟批次上。

Edit Detection 成品拆回時間軸

把已輸出的 mp4 拉進時間軸 → 觸發 Edit Detection → 每個原切點自動斷開。手上只剩輸出檔、要重剪或擷取精華段時用。

Auto Mask ＋ Magnetic Mask

Auto Mask：對 clip 套上 → 游標 hover 即時預覽偵測到的主體 → Inspector 勾 皮膚／頭髮／天空／植物／衣服 → 接調色或效果只作用該區。Magnetic Mask 是手控版：滴管點主體 → 它追蹤，Auto 抓不準時用。

Match Color 跨鏡頭校色

選要被校的 clip → Match Color → 指定參考影格 → 自動套色 → 微調。多機同場景挑一支當基準，其他一鍵拉齊。⚠️ O-Log2 素材要先解碼（建庫時已自動掛 LUT），再談校色。

Advanced Trimming／送 Pixelmator Pro

trim 時逐格控制入出影格，卡節奏用。右鍵某影格送 Pixelmator Pro 做縮圖、封面，存檔自動回時間軸。

我能幫你批次跑的

  • 整趟對話片一次全上字幕（SpliceKit 程式化操控 FCP 跑 Generate Captions）。
  • 同場景多機片批次校色（挑基準後套整組）。
  • 撿片後批次抽 KP／切 HL（既有 Phase D）。
💡 用法：素材備好跟我說「整趟上字幕」或「這場多機校色」，我跑完再回你結果，你只做最後校正。

  • 文字一律用 FCPX 內建 title（2026-08-24）。內建 title 的 effect UID 沒公開文件，只能你在 FCP 做好匯出 .fcpxmld 才拿得到 → 範本存 tools/fcp_title_templates，別刪。

💡 HL 與 KP 不必重複標：HL 是精彩片段（出短片），KP 是好單禎（出靜照）。HL 段裡若剛好也想要一禎靜照，再單獨點 KP。

兩個評分軸：STILL 是品質、MOV 是類型

  • STILL rating 1–5★＝品質（構圖／曝光／瞬間），跟照片同一套 4 軸法，進 LR 一起評。
  • MOV rating＝類型／用途，就是 ⭐ 分頁那張星等表；同一欄不同意義，LR 按檔案類型自然分開。
  • MOV colorLabel＝主體（紅臉／黃背影／綠風景／紫物件），由該 MOV 所有 STILL 的 label 多數決；例：抽 18 張，14 Y＋4 G → MOV＝Y。
  • LR 對影片只能 clip-level（色標／Pick／caption），沒有 frame-level marker → 挑那一禎、框精彩段在 FCPX 做（Phase C），我從 XML 抽圖／切片。

智慧抽幀（Phase A 內）

抽幀不是為了找 keeper（keeper 你在 FCPX 挑），是為了看懂這段在拍什麼、抓敏感動作／轉場那幾個瞬間；靜態無變化的區段不抽。

ffmpeg -nostdin -i MOV_<day>/<場景>/IMG_XXXX.MOV \
  -vf "select='isnan(prev_selected_t)+gte(t-prev_selected_t\,10)+gt(scene\,0.4)',showinfo" \
  -vsync vfr -q:v 2 /tmp/_extract_IMG_XXXX_%04d.jpg
參數值意義
時間保底 gte(t-prev,N)10 秒靜態長鏡頭最少每 10 秒留 1 張
scene 門檻 gt(scene,X)0.4只在明顯動作／轉場加抽；漏抓降 0.3，雷同太多升 0.5
首幀留永遠抽 t=0

一支約 70 張原始幀 → 抽 15 張上下。動態運動類保底可降回 6 秒；每個 trip 第一支先試跑再定參數。

ir_tag（分鏡＋景別，2026-09-06 版）

只解關鍵幀算 scene score（-skip_frame nokey、切點間隔 ≥1.5s），126 支 16 分鐘跑完；⚠️ 別加 -hwaccel videotoolbox，反而慢 8 倍。長鏡頭 >10 秒抽 2 張、>20 秒抽 3 張。手機影片要看套用旋轉後的顯示尺寸，直接讀寬高會判錯直橫。標籤走 sub-agent 一天一個，只寫 tags／shot_size／roll／usable／suggest_hl，不寫星等。

STILL 命名與 metadata（內嵌，不出 sidecar）

自動抽：<MOV>_s<NN>_t<秒.秒>.jpg；你自己截的：IMG_<src>-<N>_t<秒.秒>.jpg，同放 _STILL/<場景>/。

exiftool -overwrite_original -codedcharacterset=utf8 \
  -DateTimeOriginal="2026:05:15 11:46:28" -Source="IMG_6230.MOV @ t=03.02" \
  -Keywords="KP" -Keywords="<場景>" \
  -Caption-Abstract="[label:Y] [confidence:1.00 投票 8/8]" -XMP-dc:Description="…同上…" \
  -XMP-lr:hierarchicalSubject="影片來源|IMG_6230"  IMG_6230_s03_t03.02.jpg
  • 不加 -o＝直接寫進 JPG；-codedcharacterset=utf8 沒加中文 caption 會亂碼（九州 trip 踩過）。
  • Caption 格式：我寫 turn 0 [label:Y] [confidence:0.93 投票 14/15]，你 audit 後用 | append，永遠不覆寫（它同時是對話日誌）。
  • KF 放 keyword 欄不放 caption；時間一律 2 位小數，排序才對。
  • 雙寫鐵則：catalog SQL＋JPG 內嵌 XMP，catalog 崩可從 XMP 讀回。

Pick=-1 清理（釋出空間）

你在 LR 把 MOV 標 Reject → 我明確跑 cleanup 才處理：先搬 _TRASH/<場景>/ 隔離 7 天再真刪（誤標可救回）；刪 MOV 本體，不刪已抽的 STILL／KP。不自動觸發。
