V2.12026-06-03

把散在三份文件（FCPX 操作速查、NG/KP/HL/KF schema、7 步 pipeline）彙整成一本完整攻略書，並依當天討論定下這些工序：

  • 智慧抽幀減量：抽幀從「每 3 秒 + 場景偵測」改成「場景偵測為主、靜態 10 秒才保底 1 張」。一支約 70 張原始幀 → 抽 ~15 張。目的從「找 keeper」轉成「看懂這段是幹嘛用的」。
  • KP（好單禎）操作確定：FCPX i/o 同一禎 + keyword KP_R/Y/G/P（位置 + 主體分類一鍵）。畫質無損（Robert 從原片抽 4K），分類寫進 XMP 讓 LR import 直接讀。
    ※ 過程中曾誤把此法當「螢幕截圖」建議改 marker，已更正：i/o+keyword 一鍵更省，維持原做法。
  • HL（精彩瞬間）定義：以 keyword + i/o 範圍為準，Favorite(F) 只是 FCPX 綠色視覺輔助；clip 給 rating 4★/5★。Robert 切短片段放網路相簿當「動態照片」觀賞，段邊界 = i/o 框的範圍。
  • 1★ 改名「長篇發表（去 NG）」：i/o 框整段 + 段內壞鏡頭按 Delete(Reject) → Robert 去 NG 後把好段拼成一支完整檔。
    ※ 其他類型 NG 維持「只標不切」，只有 1★ 會真的切掉拼接。
  • 結構原則：主書 = 乾淨完整攻略書（只講現在怎麼做）；更新過程收進這頁。
