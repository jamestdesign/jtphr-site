① 一頁流程速覽

匯入素材到 Event（Leave files in place）→ 標 Favorite / Keyword / Marker ↓ Smart Collection 篩出 KP / HL / NG ↓ File → Export XML → 拿到 .fcpxml ↓ Robert 腳本讀 fcpxml → ffmpeg 抽 HL 片段 + KP 單禎 ↓ 出到 _HL/<scene>/ 和 _KP/<scene>/
💡 小貼士：你的工作只有「判斷」（哪段 HL、哪幀 KP），剩下的命名、抽片段、進資料夾全部腳本自動跑。FCPX 標完 → export XML → 丟給腳本 → 結束。

② 匯入注意事項

HDR 對話框：選 Keep as Standard (SDR)

⚠️ 第一次匯入 HDR 素材會跳出

FCPX 會問「Would you like to switch the library to HDR?」
答：Keep as Standard (SDR)

  • 撿片用不到 HDR colorspace
  • SDR Library 一樣能匯 HDR clip，FCPX 不會擋
  • 之後出 SDR 給 IG / YouTube / LINE 比較單純
  • 真的要 HDR 出片時，另外開新 Library 設成 HDR 就好

Library 匯入模式：Leave files in place

模式搬硬碟會斷？Library 大小推薦
Copy to library ❌ 永遠不斷 巨大（含素材） ⚠️ 不推（影片太肥）
Leave files in place ⚠️ 路徑變要 reconnect 一次 小（< 100MB） ✅ 推
Symlink ⚠️ 同上 小 ❌ 沒必要
💡 小貼士：選 Leave files in place 並把 _MOV/ 跟 Library 都放在 trip 資料夾內。搬 NAS 後第一次開啟會跳「missing files」，按 Locate All... 指向新的 _MOV/ 路徑，FCPX 一次重連全部 clip。

③ 資料夾結構

2026-MM-DD <trip 名>/
├── 2026-MM-DD <trip>_LR/              ← LR catalog（主管理）
├── _MOV/                              ← 影片素材實體放這
│   ├── <場景 A>/IMG_xxxx.mov
│   └── <場景 B>/IMG_yyyy.mov
├── 2026-MM-DD <trip>_FCP/             ← FCPX library 獨立放
│   └── Library.fcpbundle              ← 只記引用，素材不複製
├── _HL/                               ← 腳本輸出：精選片段
│   └── <場景>/IMG_xxxx_HL02-04.mp4
├── _KP/                               ← 腳本輸出：抽單禎
│   └── <場景>/IMG_xxxx_KP02.jpg
└── _export/                           ← photo 出片（既有）
    └── <場景>/
💡 小貼士：LR catalog 跟 FCP Library 放在獨立子資料夾，不要塞同一層。它們各自會頻繁讀寫、各自要備份、各自暫存檔位置不同，分開管理最乾淨。

⑤ Keyword 設定（Cmd+K 綁快捷鍵）

建議綁定

快捷鍵Keyword意義
Ctrl+1 HL High Light — 精彩瞬間（範圍 keyword，腳本切獨立 mp4 出片）
Ctrl+2 KP Keep — 整段剪輯保留（劇本素材，HL ⊆ KP）
Ctrl+3 NG No Good — 失誤段（只標不切，劇本跳過）

綁定步驟（一次性設好）

  1. 選任一 clip 範圍（I 入點 + O 出點），按 Cmd+K 開 Keyword Editor
  2. 第 1 格打 HL、第 2 格打 KP、第 3 格打 NG → 自動綁 Ctrl+1/2/3
  3. 關閉 Keyword Editor，之後撿片：I/O 標範圍 → 按綁定鍵 → 一秒套用
💡 小貼士：之後想加新 keyword（例如場景名）直接打第 4 格、第 5 格，FCPX 自動綁 Ctrl+4、Ctrl+5。最多 9 格。

Smart Collection 自動聚合

側邊欄 Event 底下會出現 HL / KP / NG 三個自動聚合的 Smart Collection。點任一個 → 只看到那批 keyword 標過的範圍，不用搜尋、不用篩選，一鍵到位。

💡 小貼士：Keyword 跟 Favorite 是獨立兩層，不會打架。一段可以同時是 Favorite + KP keyword + HL keyword，三層各自獨立篩。

⑥ Marker 用法（M + 顏色 / 命名）

Marker 是「單一時間點」

用途：標抽單禎的位置（KP — 你想要這一禎當靜態圖出）。按 M 在 playhead 位置打 marker。

Marker 顏色限制

顏色FCPX 語意用於這個 cheat sheet
🔵 藍Standard預設，按 M 直接是這個
🔴 紅To Do標「待後製」
🟢 綠Completed標「已 OK」
🟠 橘Chapter不建議（會跑章節列表）
⚠️ 沒有黃色 marker

如果你要紅黃綠三色分級 KP，FCPX 沒有黃色。
解法：用 Marker 名稱帶顏色 tag，不靠 marker 本身顏色。

命名方案（推薦）

Marker 名稱意義腳本抽圖檔名
KP_R 或 KP_精選最高優先IMG_xxx_KP02_R.jpg
KP_Y 或 KP_次選次優先IMG_xxx_KP05_Y.jpg
KP_G 或 KP_候補備案IMG_xxx_KP07_G.jpg
KP單純標位置IMG_xxx_KP02.jpg
💡 小貼士：連續看片時優先按 Option+M，一個動作完成「打 + 命名」。事後再回頭逐個命名很容易漏。

⑦ FCPX 操作 ↔ Schema 對應

你在 FCPX 用 Favorite / Keyword / Marker 三層操作，對應到 schema 的 NG / KP / HL / KF 概念如下：

SchemaFCPX 操作用途
HL High Light Keyword HL（範圍）
I/O + Ctrl+1		 精彩段 → ffmpeg 切獨立 mp4 出片
KP Keep Keyword KP（範圍）
I/O + Ctrl+2		 剪輯保留段 → 段中間抽 1 幀代表（劇本縮圖）
NG No Good Keyword NG（範圍）
I/O + Ctrl+3		 失誤段，只標不切（劇本跳過）
KF Key Frame 不在 FCPX 標 LR STILL Pick=1 反推回 MOV 時間點，腳本自動寫進 MOV keyword（KF:XX.XX）
Marker（單禎抽圖） M 或 Option+M 指定哪一禎抽出來當 STILL（手動補位）
Favorite（F 鍵） F 「入選」單獨一層，跟 keyword 並存。可選用，腳本目前不抓。
💡 小貼士：KF 不用你標。你只標 NG / KP / HL（範圍 keyword）+ Marker（單禎位置），KF 是 LR 那邊評完 STILL 後腳本自動反推回來的。

⑧ Export XML 三步

FCPXML 是什麼？FCPX 把所有 Favorite / Keyword / Marker / clip path 匯出成的 XML 文字檔。類比：跟 LR 的 XMP sidecar 同概念，但範圍是整個 Event。腳本讀這個檔來知道你標了什麼。

三步

  1. 選中 Event（側邊欄 Libraries → 點 Event，不是 Project / 不是 Library 最上層）
  2. File → Export XML...
    • Metadata view：選 General 或 All
    • XML Version：選最新（1.10 或更新）
  3. 儲存：命名 <trip 名>_<日期>.fcpxml，放 trip 根目錄或 Library 同層
💡 小貼士：每次 export 都是當下狀態的快照，不會自動同步。標完一輪 → export 一次 → 跑腳本。中途又改了標記要再 export 一次。

⑨ 搬 NAS reconnect SOP

⚠️ FCPX 沒有真正的相對路徑

Library 記的是絕對路徑。從 X10 Pro 搬到 NAS 後第一次開啟會跳「missing files」。但 FCPX 有智能 reconnect，一次指認資料夾就全好。

搬 NAS 5 步

  1. FCPX 關閉
  2. 整個 trip 資料夾搬到 NAS（_MOV/、LR catalog、FCP Library 一起搬）
  3. 從 NAS 雙擊開 Library.fcpbundle
  4. 跳出「missing files」對話框 → 點 Locate All...
  5. 選 NAS 上的 _MOV/ 資料夾 → FCPX 自動把所有 clip 重連
💡 小貼士：關鍵在於 _MOV/ 跟 Library 的相對結構不變。如果你搬完後 _MOV/ 改名或拆散，Locate 就要逐個指，會非常痛苦。整個 trip 資料夾原樣搬，最省事。

⑩ 暫存清理 SOP（瘦身 Library）

三類暫存可清

類型可重建？清掉影響
Render files（背景渲染）✅下次播放時自動重建
Cache files（縮圖/波形）✅下次瀏覽時自動重建
Optimized / Proxy Media✅切回原檔播放，需要時可重新轉碼

清理步驟

  1. FCPX 內，選中 Library（最上層那個圖示）
  2. File → Delete Generated Library Files...
  3. 勾選 Delete All Render Files / Optimized Media / Proxy Media
  4. 按 Delete → 通常可瘦 30~70%

清理時機

  • 出完片、要搬 NAS 前 → 清一次
  • Library 超過 50GB → 清一次
  • 季度封存時 → 清光 + 壓縮整個 trip 資料夾
💡 小貼士：不會刪你的剪輯、keyword、marker。FCPX 只清「衍生暫存」，工作成果 100% 保留。

⑪ 動手前 checklist

✅ 新 trip 開工前確認
  • ☐ Trip 資料夾結構就位（_MOV/ 場景分好）
  • ☐ 新建 FCP Library 在 trip/<trip>_FCP/
  • ☐ 匯入 _MOV/ → 取消勾「Copy to library」
  • ☐ 遇到 HDR 對話框 → Keep as Standard (SDR)
  • ☐ Keyword 三格綁好（HL / KP / NG → Ctrl+1/2/3）
  • ☐ List view 或 Filmstrip 切到你順手的（Ctrl+H）
📤 撿完一輪要交給 Robert
  • ☐ 選中 Event → File → Export XML... → 最新版本
  • ☐ 命名 <trip 名>_<日期>.fcpxml
  • ☐ 把 .fcpxml 路徑 + _MOV/ 路徑傳給 Robert
  • ☐ Robert 跑腳本 → 輸出到 _HL/<scene>/ + _KP/<scene>/
🚨 千萬不要
  • ❌ 不要勾「Copy to library」（影片素材會重複，硬碟爆掉）
  • ❌ 不要選 Switch to HDR（撿片用不到）
  • ❌ 搬硬碟後不要逐個 clip 手動 reconnect（用 Locate All... 一次搞定）
  • ❌ 不要把 LR catalog 跟 FCP Library 放同一個子資料夾
  • ❌ _MOV/ 結構移動完不要改名（會破壞 Library 重連邏輯）
