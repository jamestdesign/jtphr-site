① 一頁流程速覽

匯入素材到 Event（Leave files in place）→ HDR 對話框選 SDR ↓ 撿片：看整支 MOV 判類型 → Ctrl+1~5 標 Star ↓ 中途看到精彩禎 → I/O 標位置 + 打 KP（一個關鍵字就好） ↓ 看到失誤段 → I/O 框範圍 + Delete (NG) ↓ File → Export XML → 拿到 .fcpxml（給 Robert 腳本讀） ↓ Robert 自動化：抽 KP 禎 + 寫 LR catalog + 走 schema 流程 （評分品質在 LR 內補）
💡 小貼士：FCPX 撿片不評分品質（評分轉 LR 對 STILL 做）。FCPX 只標：① 整支 MOV 屬哪種類型、② 哪些禎要抽出來、③ 哪段是失誤要跳過。

② 匯入注意事項

HDR 對話框：選 Keep as Standard (SDR)

⚠️ 第一次匯入 HDR 素材會跳出

FCPX 會問「Would you like to switch the library to HDR?」
答：Keep as Standard (SDR)

  • 撿片用不到 HDR colorspace
  • SDR Library 一樣能匯 HDR clip，FCPX 不會擋
  • 之後出 SDR 給 IG / YouTube / LINE 比較單純

Library 匯入模式：Leave files in place

模式搬硬碟會斷？Library 大小推薦
Copy to library ❌ 永遠不斷 巨大（含素材） ⚠️ 不推
Leave files in place ⚠️ 路徑變要 reconnect 一次 小（< 100MB） ✅ 推
💡 小貼士：選 Leave files in place 並把 _MOV/ 跟 Library 都放在 trip 資料夾內。搬 NAS 後第一次開啟會跳「missing files」，按 Locate All... 一次重連全部 clip。

③ 資料夾結構

2026-MM-DD <trip 名>/
├── 2026-MM-DD <trip>_LR/              ← LR catalog（主管理）
├── _MOV/                              ← 影片素材 + FCP Library 一起放
│   ├── <場景 A>/IMG_xxxx.mov
│   ├── <場景 B>/IMG_yyyy.mov
│   └── Library.fcpbundle              ← FCPX library 放這（2026-06-02 拍板）
├── _STILL/                            ← VLM 抽幀（自動化層輸出）
│   └── <場景>/IMG_xxxx_sNN_tXX.XX.jpg
├── _KP_preview/                       ← KP 抽禎（James 指令觸發）
│   └── <clip>_kpNN_tXX.XX.jpg
└── _export/                           ← 出片區
    └── <場景>/
💡 2026-06-02 拍板：FCP Library 放進 _MOV/ 跟素材同層，一起搬就一起搬不分離。Library 用「Leave files in place」模式引用同層的 <場景>/<clip>.mov，相對路徑距離最短，reconnect 最穩。
💡 為什麼不放 trip 根層或獨立子層：放 trip 根層 → 跟 LR catalog 同層容易混淆。放獨立 <trip>_FCP/ → 多一層、且 Library 跟素材跨資料夾引用，搬移後 reconnect 路徑距離較遠。放 _MOV/ 內 = 影片相關的東西全在一處，搬硬碟最省事。

⑤ Star1~5（整支 MOV 類型，對應原 schema）

Star1~Star5 keyword 標的是「整支 MOV 屬於哪個類型」，對應原 schema 的 MOV rating 0~5★。標法：選整支 clip（X）→ Ctrl+1~5。

5 種類型 + 出片規則

快捷鍵Keyword類型出片規則
Ctrl+5 Star5 史詩級保留（婚禮 / 作品集 / 首映） P=1 → 直接壓縮出片 + 評估進入剪輯
Ctrl+4 Star4 精彩瞬間 P=1 → 直接壓縮出片 + 二次剪輯
Ctrl+3 Star3 保留（暫共用 FCPX 預設片段 F 功能） 進剪輯流程
Ctrl+2 Star2 活動攝影（演唱會 / 說明會 / 實境秀） 把 NG 去掉後整場剪出做紀錄觀看，不精修
Ctrl+1 Star1 專題報導（課程整段） 雖枯燥但要聽教學 + NG 註記切除版剪輯出片
— （不標） 0★ 生活紀錄（預設） 即使 P=1 也不直接出片，KF + KP 仍可進劇本

分水嶺

直接出片 vs 剪輯出片的分界在 Star4 ✓

💡 小貼士：Star 是整支 MOV 一個，不是分段標。選整支 clip 再按 Ctrl+1~5，整支套上 keyword。同一支 MOV 不該有兩個 Star。

視覺強化：Star4 / Star5 加 Favorite (F)

匯入時 FCPX 自動把場景名標成 keyword → 整支 clip 已是藍色條。再標 Star1~5 還是藍色條（藍色不分 keyword 種類），無法視覺分辨哪些是精彩級。

解法：Star4 / Star5 加 F（Favorite）→ 多一條綠色覆蓋藍色 → 一眼分辨「必出片候選」。

條色疊加邏輯

屬性條色
Keyword（任何 keyword，含場景 / Star / KP）藍色條
Favorite（F）綠色條（覆蓋藍色上）
Reject（Delete）紅斜線
Marker中間白色小三角

F 的關鍵特性

  • 布林狀態，不會疊加：對同一範圍按 F 多次 = 標一次，內部只有一個 Favorite 標記
  • F 鍵不會 toggle off：要清除 Favorite 用 U（Unrate），再按 F 沒效果
  • 跟 keyword 並存：F 不影響任何 keyword，兩者各自獨立

建議分配

Star加 F？視覺
Star5（史詩）✅ 加綠 + 藍
Star4（精彩瞬間）✅ 加綠 + 藍
Star3（保留）❌ 不加純藍
Star2 / Star1❌ 不加純藍

Browser 內快速掃過 → 綠色條 = 必出片候選（Star4+5），藍色條 = 一般保留 / NG / 場景。

💡 小貼士：Favorite 是 1-bit 沒分級。如果 Star3/4/5 全加 F 後視覺都一樣綠，分不出 3 4 5 哪個更精彩。所以建議只給最高優先級的 Star4/5 用 F 強化。
⚠️ F 是視覺輔助，Star keyword 才是 source of truth

Robert 腳本判斷「必出片候選」時看的是 Star4 / Star5 keyword，不是 F。 即使 James 撿片時忘了加 F，只要 keyword 有標 Star4/Star5 → 腳本一樣會識別 → 走必出片流程。F 純粹是給 James 自己 Browser 內視覺掃片用，不影響任何自動化判斷。

⑥ KP（抽禎指令）

🆕 2026-08-23 改版：只打 KP 一個關鍵字，不用再分 R/Y/G/P——那四個快捷鍵拿回去自己用。 Robert 出圖後看畫面自動補色標（規則不變：紅=臉 黃=背影 綠=風景 紫=物件），你進 LR 看到的跟以前一樣。

意思仍是「這個時點請抽一張禎當 STILL」：I/O 框好位置 → 打 KP。

動作Keyword誰判斷主題
I/O ＋ 打關鍵字KPRobert 出圖後看畫面補 R/Y/G/P 色標
舊的 KP_R/Y/G/P 照樣吃（之前的 trip 不會壞）；覺得哪張色標判錯，跟 Robert 講編號改單張。

標法：I/O 同一禎（單點）

  1. 看片到想抽的那禎 → 按 I 標入點
  2. 不移動 playhead → 按 O 標出點（同位置 = 單禎範圍）
  3. 按 Ctrl+6~9 套 KP 分類
💡 手滑救援：如果 I/O 不小心錯位變成範圍（例：第 5.2 秒到第 5.4 秒）— 沒關係，腳本自動抽範圍第一禎。標完不必回去修。

腳本動作

看到 keyword="KP_R" 範圍 (start, end):
  if start == end:
    抽 t=start 那一禎
  else:
    抽 t=start 第一禎（手滑救援）

→ 寫進 _KP_preview/<clip>_kpNN_tXX.XX.jpg
→ 寫進 LR catalog:
  - STILL 自帶 keyword "R"（主題分類）
  - Pick=1（自動標保留）
  - rating 留空 → James 進 LR 補評分
⚠️ FCPX 不給 STILL 評分

FCPX 內沒辦法給抽禎品質評分（FCPX 的 rating 系統只有 Favorite/Reject 兩個 bit）。評分轉到 LR 內補：抽出來的 STILL 進 LR 後你看圖評 1~5★。FCPX 端只負責「分類分標籤 + 標 Pick」。

⑦ Delete = NG 失誤段

FCPX 內建 Reject 鍵 Delete 直接拿來標 NG（失誤段，劇本生成跳過）。

標法

  1. 看到失誤段（對焦不準 / 穿幫 / 拍壞）→ I/O 框範圍
  2. 按 Delete → 整段標 Reject（橫線符號顯示）
  3. U 可還原（如果標錯）

腳本動作

  • 看到 Reject 範圍 → 視為 NG → 劇本生成跳過
  • 原 MOV 不切（schema 拍板：NG 只註記不切）
💡 小貼士：Reject 在 Smart Collection 內可篩「All / Hide Rejected / Rejected Only」三種視角，撿片時隨時切換看。

⑧ Marker 用法（純時間點標記）

Marker 是「單一時間點」，跟 keyword（範圍）是兩個系統。撿片時用途：標一個特別的時間點給自己留註記，不觸發任何自動化。

Marker 快捷鍵

M打藍色 standard marker
Option+M打 marker + 開命名框
Ctrl+M刪 marker（playhead 在 marker 上時）
💡 重要區分：Marker 是「純標位置」用，不用來標 NG/KP/HL/KF。NG/KP/HL/KF 是 schema 概念：NG 用 Delete、KP 用 Ctrl+6~9 keyword、HL/KF 都是自動化層的事，跟 marker 無關。

⑨ Export XML 三步

FCPXML 是什麼？FCPX 把所有 keyword / Reject / Marker / clip path 匯出成的 XML metadata。類比 LR 的 XMP sidecar。Robert 腳本讀這個檔來知道 James 標了什麼。

三步

  1. 選中 Event（側邊欄 Libraries → 點 Event，不是 Project / 不是 Library 最上層）
  2. File → Export XML...
    • Metadata view：選 General 或 All
    • XML Version：選最新（1.10 或更新）
  3. 儲存：命名 <trip 名>_<日期>.fcpxml 或 .fcpxmld，放 _MOV/ 跟 Library 同層

兩種輸出格式（FCPX 新版預設 .fcpxmld）

副檔名性質內容
.fcpxml 純 XML 文字檔 單一檔案，文字編輯器打得開
.fcpxmld Package / Bundle（看起來是檔案實際是資料夾） 內含 Info.fcpxml + 縮圖 / poster 等資源
💡 Robert 腳本兩種都吃：自動偵測副檔名 — .fcpxmld 進 bundle 找 Info.fcpxml 再 parse；.fcpxml 直接 parse。你不用管選哪個，FCPX 預設給什麼就用什麼。
💡 想看 .fcpxmld 內 XML 內容：Finder 內對 .fcpxmld 右鍵 → 「顯示套件內容」 → 進去看到 Info.fcpxml。
💡 小貼士：每次 export 都是當下狀態的快照。標完一輪 → export 一次 → 跑腳本。中途又改了標記要再 export。

⑩ 搬 NAS reconnect SOP

⚠️ FCPX 沒有真正的相對路徑

Library 記的是絕對路徑。從 X10 Pro 搬到 NAS 後第一次開啟會跳「missing files」。但 FCPX 有智能 reconnect，一次指認資料夾就全好。

搬 NAS 5 步

  1. FCPX 關閉
  2. 整個 trip 資料夾搬到 NAS（_MOV/、LR catalog、FCP Library 一起搬）
  3. 從 NAS 雙擊開 Library.fcpbundle
  4. 跳出「missing files」對話框 → 點 Locate All...
  5. 選 NAS 上的 _MOV/ 資料夾 → FCPX 自動把所有 clip 重連
💡 小貼士：關鍵在 _MOV/ 跟 Library 的相對結構不變。整個 trip 資料夾原樣搬，最省事。

⑪ 暫存清理 SOP（瘦身 Library）

三類暫存可清

類型可重建？清掉影響
Render files✅下次播放時自動重建
Cache files✅下次瀏覽時自動重建
Optimized / Proxy Media✅切回原檔播放，需要時可重新轉碼

清理步驟

  1. FCPX 內，選中 Library（最上層那個圖示）
  2. File → Delete Generated Library Files...
  3. 勾選 Delete All Render Files / Optimized Media / Proxy Media
  4. 按 Delete → 通常可瘦 30~70%

清理時機

  • 出完片、要搬 NAS 前 → 清一次
  • Library 超過 50GB → 清一次
  • 季度封存時 → 清光 + 壓縮整個 trip 資料夾
💡 小貼士：不會刪 keyword / marker / Reject 標記。FCPX 只清「衍生暫存」，James 撿片成果 100% 保留。
